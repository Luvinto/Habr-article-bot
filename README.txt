# 📚 Habr Article Curator

Интеллектуальный куратор статей с Хабра для начинающих Python-разработчиков. Автоматически анализирует и отбирает наиболее полезные материалы по направлениям: Python, AI/ML, Web-разработка (бэкенд) и Информационная безопасность.

## 🎯 Назначение

Проект решает проблему информационной перегрузки: из сотен статей ежедневно публикуемых на Хабре, система отбирает только те, которые реально помогут Junior-разработчику расти профессионально в ближайшие 3-6 месяцев.

## ✨ Возможности

- 🤖 **Интеллектуальная фильтрация** — использование LLM для анализа качества и релевантности контента
- 📊 **Система скоринга** — оценка каждой статьи по шкале 1-10, отбор только лучших (score ≥ 9)
- 🎯 **Точная категоризация** — автоматическое определение основной темы: Python, AI/ML, Web, ИБ или Карьера
- 📦 **Пакетная обработка** — эффективная работа с большими объемами данных (140+ статей)
- 🔒 **Жесткие критерии** — отсечение мусорного контента, маркетинга, воды и нерелевантных тем
- 📋 **Структурированный вывод** — результат в формате JSON для дальнейшей обработки

## 🚀 Быстрый старт

### Требования

- Python 3.10+
- API-ключ для LLM (OpenAI, Anthropic, или совместимый провайдер)
